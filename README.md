# Fabric Bazaar – Manual Testing Project

## Project Overview
Manual testing of Fabric Bazaar E-commerce Website,
Mobile Application, and Admin Panel.

## Testing Activities
- Functional Testing
- UI Testing
- Regression Testing
- Test Case Execution
- Bug Identification and Reporting
- Retesting

## Modules Tested
- User Registration & Login
- Product & Category
- Wishlist
- Cart
- Order Management
- Profile Management
- Admin Panel

## Skills Used
- Manual Testing
- Test Case Design
- Bug Reporting
- Functional Testing
- UI Testing

## Project Objective
To identify defects, verify functionality, and improve
the overall quality of the application.
